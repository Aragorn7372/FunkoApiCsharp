class FunkoApi.Handler.Funkos.FunkosWebSocketHandler ( ILogger< FunkosWebSocketHandler >  logger)

Handler de WebSocket para gestionar conexiones de notificaciones de funkos.

Características:

  • Notificaciones de broadcast a TODOS los clientes conectados.
  • No requiere autenticación (público).
  • Ideal para dashboards públicos y catálogos en tiempo real.

EndPoint de conexión:

ws://localhost:5000/ws/funkos

Ejemplo de conexión desde cliente JavaScript:

// Sin autenticación requerida
const ws = new WebSocket('ws://localhost:5000/ws/funkos');
ws.onmessage = (event) => {
const data = JSON.parse(event.data);
console.log('Notificación de funko:', data);
};

Casos de uso:

  • Dashboards públicos que muestran nuevos funkos.
  • Actualización de catálogos en tiempo real.
  • Sistemas de inventario que monitorean cambios.

Ejemplo de respuesta de notificación:

{
"entity": "funkos",
"type": "funko_CREADO",
"funkoId": 123,
"funko": {
"id": 123,
"nombre": "Nuevo funko",
"precio": 99.99,
"stock": 50
},
"timestamp": "2025-01-18T10:30:00Z"
}

Tipos de eventos:

funko_CREADO Se creó un nuevo funko. Incluye datos del funko.
funko_ACTUALIZADO Se actualizó un funko. Incluye datos actualizados.
funko_ELIMINADO Se eliminó un funko. funko es null, solo envía funkoId.

Maneja una nueva conexión WebSocket para funkos.

Parámetros
contextContexto HTTP de la conexión.
webSocketInstancia del WebSocket.
Devuelve
Tarea asíncrona representando la conexión.

Proceso de conexión:

  1. El cliente se conecta sin necesidad de autenticación.
  2. Se genera un connectionId único para la sesión.
  3. La conexión se almacena en el diccionario de conexiones.
  4. Cuando se cierra la conexión, se elimina del diccionario.

Notifica a todos los clientes conectados un evento de funko.

Parámetros
notificacionDatos de la notificación.
Devuelve
Tarea asíncrona de la notificación.

Ejemplo de uso:

// Notificar que se creó un nuevo funko
await NotifyAsync(new funkoNotificacion(
funkoNotificationType.CREATED,
123,
funkoDto // Datos del funko
));
// TODOS los clientes conectados recibirán esta notificación
// Notificar que se eliminó un funko
await NotifyAsync(new funkoNotificacion(
funkoNotificationType.DELETED,
123,
null // No hay datos del funko eliminado
));

◆ WebSocketConnectionManager()

class FunkoApi.Handler.Funkos.WebSocketConnectionManager ( ILogger< WebSocketConnectionManager >  logger)

Administrador centralizado de conexiones WebSocket para notificaciones en tiempo real.

Esta clase proporciona funcionalidades para gestionar conexiones WebSocket de múltiples clientes, permitiendo comunicación bidireccional en tiempo real para notificaciones de cambios en productos Funko.

Características principales:

  • Gestión thread-safe de conexiones usando colecciones concurrentes
  • Soporte para mensajería uno-a-uno (unicast)
  • Soporte para mensajería uno-a-todos (broadcast)
  • Soporte para grupos/canales (envío selectivo a múltiples clientes)
  • Validación automática del estado de conexiones antes de enviar mensajes

Thread-Safety: Todas las operaciones son thread-safe gracias al uso de ConcurrentDictionary<TKey, TValue>.

Uso típico en un endpoint WebSocket:

app.UseWebSockets();
app.Map("/ws/funkos", async context =>
{
if (context.WebSockets.IsWebSocketRequest)
{
var webSocket = await context.WebSockets.AcceptWebSocketAsync();
var connectionId = connectionManager.AddConnection(webSocket);
try
{
await HandleWebSocketConnection(webSocket, connectionId);
}
finally
{
connectionManager.RemoveConnection(connectionId);
}
}
});

Diccionario thread-safe que almacena todas las conexiones WebSocket activas indexadas por su ID único.

Diccionario thread-safe que almacena grupos/canales de conexiones. La clave es el nombre del grupo y el valor es un conjunto de IDs de conexión.

Permite agrupar conexiones para enviar mensajes selectivos (por ejemplo, solo a usuarios suscritos a una categoría específica).

Parámetros

Devuelve
Un identificador único (GUID) asignado a la conexión que puede usarse para operaciones posteriores.

Este método es thread-safe y puede ser llamado desde múltiples hilos concurrentemente. El ID generado debe almacenarse para poder enviar mensajes específicos o eliminar la conexión posteriormente.

var webSocket = await context.WebSockets.AcceptWebSocketAsync();

Console.WriteLine($"Nueva conexión: {connectionId}");

Elimina una conexión WebSocket del administrador.

Parámetros
connectionIdEl identificador único de la conexión a eliminar.

Este método también elimina la conexión de todos los grupos a los que pertenecía. Es thread-safe y puede ser llamado múltiples veces con el mismo ID sin efectos secundarios.

Importante: Este método NO cierra el WebSocket subyacente. El llamador es responsable de cerrar la conexión WebSocket antes o después de llamar a este método.

Envía un mensaje de texto a una conexión WebSocket específica.

Parámetros
connectionIdEl identificador único de la conexión destino.
messageEl mensaje de texto a enviar (generalmente JSON serializado).
Devuelve
Una tarea que representa la operación asíncrona de envío.

Este método verifica automáticamente que la conexión exista y esté en estado Open antes de enviar. Si la conexión no existe o no está abierta, el método no realiza ninguna acción y no lanza excepciones.

El mensaje se codifica en UTF-8 y se envía como un mensaje de texto WebSocket completo (fin = true).

var message = JsonSerializer.Serialize(new
{
type = "NOTIFICATION",
data = "Nuevo Funko agregado"
});
await connectionManager.SendMessageAsync(connectionId, message);
Excepciones
WebSocketExceptionPuede lanzarse si ocurre un error durante el envío del mensaje (conexión perdida, timeout, etc.).

Envía un mensaje a todas las conexiones WebSocket activas (broadcast).

Parámetros
messageEl mensaje de texto a enviar a todos los clientes conectados.
Devuelve
Una tarea que representa la operación asíncrona de broadcast.

Este método filtra automáticamente solo las conexiones en estado Open antes de enviar. Los mensajes se envían secuencialmente a cada conexión.

Rendimiento: Si hay muchas conexiones activas, considere usar Task.WhenAll para envíos paralelos, aunque esto puede consumir más recursos.

Si algún envío falla, el error se propagará y detendrá el broadcast a las conexiones restantes. Considere agregar manejo de errores si requiere resiliencia.

Notificar a todos los clientes sobre un nuevo producto:

var notification = new WebSocketMessage
{
Type = "FUNKO_CREATED",
Payload = JsonSerializer.Serialize(funkoDto),
Timestamp = DateTime.UtcNow
};
await connectionManager.BroadcastAsync(JsonSerializer.Serialize(notification));

Envía un mensaje a todas las conexiones de un grupo específico.

Parámetros
groupNameEl nombre del grupo/canal al que enviar el mensaje.
messageEl mensaje de texto a enviar.
Devuelve
Una tarea que representa la operación asíncrona de envío grupal.

Este método envía mensajes en paralelo a todas las conexiones del grupo usando Task.WhenAll. Solo se envía a conexiones que estén en estado Open.

Si el grupo no existe o está vacío, el método no realiza ninguna acción.

Casos de uso:

  • Notificar solo a usuarios suscritos a una categoría específica
  • Enviar actualizaciones a usuarios en una sala de chat
  • Notificaciones por región geográfica
// Agregar conexiones a un grupo
connectionManager.AddToGroup(connectionId1, "categoria:marvel");
connectionManager.AddToGroup(connectionId2, "categoria:marvel");
// Enviar mensaje solo a ese grupo
var message = JsonSerializer.Serialize(new WebSocketMessage
{
Type = "CATEGORY_UPDATE",
Payload = "Nuevos Funkos de Marvel disponibles"
});
await connectionManager.SendToGroupAsync("categoria:marvel", message);

Agrega una conexión a un grupo/canal específico.

Parámetros
connectionIdEl identificador de la conexión a agregar.
groupNameEl nombre del grupo al que agregar la conexión.

Si el grupo no existe, se crea automáticamente. Una conexión puede pertenecer a múltiples grupos simultáneamente.

Este método es thread-safe y puede ser llamado concurrentemente.

// Agrupar por categorías de interés
connectionManager.AddToGroup(connectionId, "categoria:marvel");
connectionManager.AddToGroup(connectionId, "categoria:dc");
// Agrupar por tipo de notificación
connectionManager.AddToGroup(connectionId, "notificaciones:precios");

Elimina una conexión de un grupo específico.

Parámetros

Si el grupo no existe o la conexión no pertenece al grupo, el método no realiza ninguna acción. Este método es thread-safe.

// Usuario se desuscribe de notificaciones de una categoría

Obtiene todas las conexiones WebSocket activas (en estado Open).

Devuelve
Una colección enumerable de instancias de WebSocket que están en estado Open.

Este método filtra automáticamente las conexiones cerradas o en otros estados. El resultado es una instantánea en el momento de la consulta; las conexiones pueden cambiar de estado después.

Uso típico: Monitoreo, estadísticas o inspección de conexiones activas.

var activeConnections = connectionManager.GetAllConnections();
