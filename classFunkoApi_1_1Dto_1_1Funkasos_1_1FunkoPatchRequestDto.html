Descripción detallada

Objeto de Transferencia de Datos (DTO) para solicitudes de actualización parcial (PATCH) de productos Funko.

Este DTO se utiliza en operaciones HTTP PATCH para permitir la actualización selectiva de campos de un producto Funko sin necesidad de enviar todos los datos.

A diferencia de PUT (que reemplaza todo el recurso), PATCH permite actualizar solo los campos que se incluyan en la solicitud, dejando los demás sin modificar.

Nota importante: Actualmente no hay un endpoint PATCH implementado en el controlador. Este DTO está preparado para una futura implementación de actualización parcial.

Ejemplo de payload JSON para actualizar solo el precio:

{
"price": 39.99
}

Ejemplo para actualizar nombre y categoría:

{
"nombre": "Funko Pop Iron Man Mark 85",
"categoria": "Marvel Avengers"
}

"Marvel Comics", "DC Comics", "Anime", "Star Wars"

◆ Image

string? FunkoApi.Dto.Funkasos.FunkoPatchRequestDto.Image = null
getset

Obtiene o establece la URL o ruta de la imagen del producto Funko.

Una cadena de texto opcional que representa la ruta relativa o URL de la nueva imagen del producto. Si es null o no se incluye, la imagen actual del producto no se modificará.

Este campo normalmente contiene la ruta del archivo de imagen previamente subido, no los datos binarios de la imagen.

Para subir una nueva imagen, se debe usar el endpoint con multipart/form-data que está disponible en PUT /api/funkos/{id}.

"/images/funkos/batman-dark-knight.jpg", "https://cdn.example.com/funkos/123.png"

◆ Nombre

string? FunkoApi.Dto.Funkasos.FunkoPatchRequestDto.Nombre = null
getset

Obtiene o establece el nombre del producto Funko.

Una cadena de texto opcional que representa el nuevo nombre del producto. Si se proporciona, debe tener entre 2 y 100 caracteres. Si no se incluye en la solicitud, el nombre actual del producto no se modificará.

"Funko Pop Batman", "Spider-Man (Spider-Verse)", "Baby Yoda (The Mandalorian)"

◆ Price

double? FunkoApi.Dto.Funkasos.FunkoPatchRequestDto.Price = null
getset

Obtiene o establece el precio del producto Funko.

Un valor numérico decimal opcional que representa el nuevo precio del producto en la moneda base del sistema. Debe estar en el rango de 0.01 a 9999.99. Si es null, el precio actual del producto no se modificará.

29.99, 49.95, 15.00
