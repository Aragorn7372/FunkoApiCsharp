string  Nombre 
)

Objeto de Transferencia de Datos (DTO) que representa la respuesta de una categoría.

Este record se utiliza para serializar y devolver información de categorías desde la API hacia los clientes. Se genera como respuesta en operaciones de consulta, creación, actualización y eliminación de categorías.

Utiliza el patrón de constructor posicional de records para inicialización concisa, con propiedades mutables adicionales para compatibilidad con serialización JSON.

Ejemplo de respuesta JSON generada por este DTO:

{
"id": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
"nombre": "Marvel Comics"
}

Obtiene o establece el identificador único de la categoría.

Un GUID que identifica de forma única la categoría en el sistema.

Esta propiedad redeclara el parámetro posicional del constructor haciéndola mutable para compatibilidad con algunos serializadores y ORMs.

Obtiene o establece el nombre de la categoría.

Una cadena de texto que describe la categoría.

Esta propiedad redeclara el parámetro posicional del constructor haciéndola mutable para compatibilidad con algunos serializadores y ORMs.

Parámetros
IdUn GUID que identifica de forma única la categoría en el sistema. Este valor es generado automáticamente por la base de datos al crear la categoría.

3fa85f64-5717-4562-b3fc-2c963f66afa6

Parámetros
NombreUna cadena de texto que representa el nombre de la categoría.

"Marvel Comics", "DC Comics", "Anime", "Disney"
