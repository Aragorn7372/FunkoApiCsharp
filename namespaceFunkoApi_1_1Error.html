record FunkoApi.Error.CategoriaError ( string  Error)
abstract

Clase base abstracta para todos los errores relacionados con operaciones de categorías.

Esta jerarquía de errores permite el uso de pattern matching fuertemente tipado para mapear errores de la capa de servicio a respuestas HTTP apropiadas en los controladores.

Utiliza records inmutables para garantizar que los mensajes de error no puedan ser modificados después de su creación, proporcionando thread-safety y predictibilidad.

Ejemplo de uso con CSharpFunctionalExtensions:

// En el servicio
public async Task<Result<CategoriaResponseDto, CategoriaError>> GetCategoriaAsync(Guid id)
{
var categoria = await _repository.FindByIdAsync(id);
return categoria == null
? new CategoriaNotFoundError($"Categoría {id} no encontrada")
: Result.Success<CategoriaResponseDto, CategoriaError>(MapToDto(categoria));
}
// En el controlador
return await _service.GetCategoriaAsync(id).Match(
onSuccess: dto => Ok(dto),
onFailure: error => error switch
{
CategoriaNotFoundError => NotFound(new { message = error.Error }),
CategoriaValidationError => BadRequest(new { message = error.Error }),
CategoriaBadRequestError => BadRequest(new { message = error.Error }),
CategoriaStorageError => StatusCode(500, new { message = error.Error }),
_ => StatusCode(500, new { message = "Error inesperado" })
});
