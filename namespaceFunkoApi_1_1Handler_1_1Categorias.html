class FunkoApi.Handler.Categorias.CategoriaWebSocketHandler ( ILogger< CategoriaWebSocketHandler >  logger)

Handler de WebSocket para gestionar conexiones de notificaciones de Categorias.

Características:

  • Notificaciones de broadcast a TODOS los clientes conectados.
  • No requiere autenticación (público).
  • Ideal para dashboards públicos y catálogos en tiempo real.

EndPoint de conexión:

ws://localhost:5000/ws/Categorias

Ejemplo de conexión desde cliente JavaScript:

// Sin autenticación requerida
const ws = new WebSocket('ws://localhost:5000/ws/Categorias');
ws.onmessage = (event) => {
const data = JSON.parse(event.data);
console.log('Notificación de Categoria:', data);
};

Casos de uso:

  • Dashboards públicos que muestran nuevos Categorias.
  • Actualización de catálogos en tiempo real.
  • Sistemas de inventario que monitorean cambios.

Ejemplo de respuesta de notificación:

{
"entity": "Categorias",
"type": "Categoria_CREADO",
"CategoriaId": 123,
"Categoria": {
"id": 123,
"nombre": "Nuevo Categoria",
"precio": 99.99,
"stock": 50
},
"timestamp": "2025-01-18T10:30:00Z"
}

Tipos de eventos:

Categoria_CREADO Se creó un nuevo Categoria. Incluye datos del Categoria.
Categoria_ACTUALIZADO Se actualizó un Categoria. Incluye datos actualizados.
Categoria_ELIMINADO Se eliminó un Categoria. Categoria es null, solo envía CategoriaId.

Maneja una nueva conexión WebSocket para Categorias.

Parámetros
contextContexto HTTP de la conexión.
webSocketInstancia del WebSocket.
Devuelve
Tarea asíncrona representando la conexión.

Proceso de conexión:

  1. El cliente se conecta sin necesidad de autenticación.
  2. Se genera un connectionId único para la sesión.
  3. La conexión se almacena en el diccionario de conexiones.
  4. Cuando se cierra la conexión, se elimina del diccionario.

Notifica a todos los clientes conectados un evento de Categoria.

Parámetros
notificacionDatos de la notificación.
Devuelve
Tarea asíncrona de la notificación.

Ejemplo de uso:

// Notificar que se creó un nuevo Categoria
await NotifyAsync(new CategoriaNotificacion(
CategoriaNotificationType.CREATED,
123,
CategoriaDto // Datos del Categoria
));
// TODOS los clientes conectados recibirán esta notificación
// Notificar que se eliminó un Categoria
await NotifyAsync(new CategoriaNotificacion(
CategoriaNotificationType.DELETED,
123,
null // No hay datos del Categoria eliminado
));
