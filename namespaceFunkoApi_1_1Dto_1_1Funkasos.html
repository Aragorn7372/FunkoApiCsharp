Objeto de Transferencia de Datos (DTO) que representa la respuesta de un producto Funko.

Este record se utiliza para serializar y devolver información de productos Funko desde la API hacia los clientes. Se genera como respuesta en las siguientes operaciones:

  • GET /api/funkos - Lista de todos los productos Funko
  • GET /api/funkos/{id} - Consulta de un producto específico
  • POST /api/funkos - Confirmación de creación de nuevo producto
  • PUT /api/funkos/{id} - Confirmación de actualización de producto
  • DELETE /api/funkos/{id} - Confirmación de eliminación de producto

Nota de diseño: Este record utiliza campos en lugar de propiedades auto-implementadas, lo cual es inusual y genera código redundante. Considere usar un record posicional puro para mayor simplicidad.

Ejemplo de respuesta JSON generada por este DTO:

{
"id": 123,
"nombre": "Funko Pop Batman Dark Knight",
"precio": 29.99,
"categoria": "DC Comics",
"imagen": "/uploads/funkos/batman-123456.jpg"
}

Ejemplo de uso en código:

var funko = new FunkoResponseDto(
Id: 123,
Nombre: "Funko Pop Iron Man",
Precio: 29.99,
Categoria: "Marvel Comics",
Imagen: "/uploads/funkos/ironman.jpg"

record FunkoResponseDto(long Id, string Nombre, double Precio, string Categoria, string Imagen)
Objeto de Transferencia de Datos (DTO) que representa la respuesta de un producto Funko.
Parámetros
IdUn número entero largo (long) que identifica de forma única el producto en el sistema. Este valor es generado automáticamente por la base de datos al crear el producto.

123, 456, 789

Parámetros
NombreUna cadena de texto que describe el nombre completo del producto, incluyendo personaje, serie o edición especial si aplica.

"Funko Pop Batman Dark Knight", "Spider-Man (No Way Home) #1109", "Baby Yoda (The Mandalorian)"

Parámetros
PrecioUn valor numérico de punto flotante que representa el precio del producto en la moneda base del sistema.

Advertencia: Se utiliza double para el precio, lo cual puede causar problemas de precisión en cálculos monetarios. Se recomienda migrar a decimal en futuras versiones.

29.99, 15.00, 49.95, 199.99

Parámetros
CategoriaUna cadena de texto que representa el nombre de la categoría del producto.

"Marvel Comics", "DC Comics", "Anime", "Star Wars", "Disney"

Parámetros
ImagenUna cadena de texto que representa la ruta relativa o URL absoluta del archivo de imagen asociado al producto.

Esta ruta apunta al archivo de imagen que fue subido durante la creación o actualización del producto. Si el producto no tiene imagen asociada, este campo puede contener una cadena vacía o una ruta por defecto.

"/uploads/funkos/batman-123456.jpg", "https://cdn.ejemplo.com/funkos/ironman.png"
