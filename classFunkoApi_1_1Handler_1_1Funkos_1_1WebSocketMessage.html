Descripción detallada

Representa la estructura estándar de un mensaje WebSocket en la aplicación.

Esta clase define el formato común para todos los mensajes enviados a través de WebSocket, proporcionando una estructura consistente para que los clientes puedan parsear y procesar mensajes.

El mensaje se serializa típicamente a JSON antes de enviarse a través del WebSocket.

Crear y enviar un mensaje de creación de Funko:

var message = new WebSocketMessage
{
Type = "FUNKO_CREATED",
Payload = JsonSerializer.Serialize(new
{
id = 123,
nombre = "Batman Dark Knight",
precio = 29.99
}),
Timestamp = DateTime.UtcNow
};
var json = JsonSerializer.Serialize(message);
await connectionManager.BroadcastAsync(json);

Ejemplo de mensaje recibido por el cliente (JSON):

{
"type": "FUNKO_CREATED",
"payload": "{\"id\":123,\"nombre\":\"Batman\",\"precio\":29.99}",
"timestamp": "2024-01-15T10:30:00Z"
}

Tipos de mensaje comunes:

  • FUNKO_CREATED - Se creó un nuevo producto
  • FUNKO_UPDATED - Se actualizó un producto existente
  • FUNKO_DELETED - Se eliminó un producto
  • CATEGORY_UPDATED - Se actualizó una categoría
  • ERROR - Ocurrió un error
  • PING - Mensaje de keep-alive

◆ Payload

string? FunkoApi.Handler.Funkos.WebSocketMessage.Payload
getset

Obtiene o establece la carga útil del mensaje.

Una cadena opcional que contiene los datos del mensaje, típicamente JSON serializado. Puede ser null para mensajes sin datos (como PING).

Para mantener flexibilidad, se usa string en lugar de un objeto tipado. Los clientes deben deserializar el payload según el tipo de mensaje.

Alternativa: Considere usar object? o JsonElement si desea serialización automática de objetos complejos.

// Payload con datos de un Funko
Payload = JsonSerializer.Serialize(new FunkoResponseDto(...))
// Payload con mensaje simple
Payload = "Operación completada exitosamente"
// Sin payload
Payload = null

◆ Timestamp

getset

Obtiene o establece la marca de tiempo UTC del mensaje.

Un DateTime en UTC que indica cuándo se creó el mensaje. Por defecto se establece en el momento de creación del objeto.

Útil para:

  • Ordenamiento temporal de eventos en el cliente
  • Detección de mensajes obsoletos o duplicados
  • Auditoría y logging
  • Cálculo de latencia de red

Se usa UTC para evitar problemas con zonas horarias.

var message = new WebSocketMessage
{
Type = "FUNKO_CREATED",
Payload = "...",
Timestamp = DateTime.UtcNow
};
// El cliente puede calcular latencia
var latency = DateTime.UtcNow - message.Timestamp;

Obtiene o establece el tipo de mensaje.

Una cadena que identifica el tipo de evento o acción del mensaje. Por convención, se usa UPPER_SNAKE_CASE.

El cliente usa este campo para determinar cómo procesar el mensaje (routing de eventos).

"FUNKO_CREATED", "FUNKO_UPDATED", "FUNKO_DELETED", "ERROR", "PING"
